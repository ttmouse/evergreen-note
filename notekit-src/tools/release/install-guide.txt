Evergreen note 安装说明
================================
版本 {{VERSION}} · 构建于 {{BUILD_DATE}} · 仅 Apple Silicon

【一、安装】
1. 把左边的 Evergreen note 拖进右边的「应用程序」文件夹（Applications）。
2. 第一次打开：在「应用程序」里右键点 Evergreen note 图标 →「打开」→
   弹窗里再点一次「打开」。
   （这个包没有 Apple 开发者签名，macOS 会拦第一次；放行之后就正常了。）
3. 如果系统仍然不让打开（提示"已损坏"或"无法验证开发者"），
   打开「终端」，粘这一行回车，然后再双击：
       xattr -dr com.apple.quarantine "/Applications/Evergreen note.app"

【二、第一次使用】
打开就是笔记界面（中文），不需要注册、不需要登录、不需要联网。
首次启动是空库，可以直接开始写；也可以在界面里导入已有的笔记数据。

【三、数据存在哪】
所有笔记都存在你自己电脑上，不上传任何服务器、不跨设备同步：
    数据目录：{{LIBRARY_DIR}}
    数据库文件：{{LIBRARY_DIR}}/notekit.db
    自动备份：{{BACKUP_DIR}}   （默认每 30 分钟一次，保留最近 20 份，退出时再备一次）
菜单「Evergreen note → 打开数据目录 / 打开备份目录 / 立即备份」都能直接用。

【四、备份与还原】
· 自动备份是静默的：到点就做，不弹窗、不打扰。
· 手动备份：菜单「Evergreen note → 立即备份」，成功后同样不打扰，只有失败才提示。
· 手动兜底：把 {{LIBRARY_DIR}} 整个文件夹拷走即可（这就是完整的一份笔记库）。
· 还原：退出应用 → 用备份的 notekit.db 覆盖 {{LIBRARY_DIR}}/notekit.db → 重新打开。

【五、注意事项】
· 只支持 Apple Silicon（M1/M2/M3/M4…）芯片的 Mac，Intel 机型无法运行。
· 纯本地应用，程序本身不联网。唯一的联网功能是「AI 助手」，需要你自己填
  OpenAI 兼容接口的 API Key 才会用到。
· 程序在 127.0.0.1:{{PORT}} 上起一个只监听本机的服务；如果这个端口被别的程序占了，
  应用会提示"本地服务启动失败"，退出那个程序再开即可。

【六、升级】
下载新版本的 dmg，把新的 Evergreen note 拖进「应用程序」覆盖旧的即可。
笔记数据在应用包外面（见第三节），升级不会动它。

【七、卸载】
把「应用程序」里的 Evergreen note 拖到废纸篓即可。
要连笔记一起删，再手动删掉 {{LIBRARY_DIR}} 和 {{BACKUP_DIR}}（删之前先备份）。

English quick start
1. Drag "Evergreen note" into Applications. First launch: right-click the icon
   -> Open -> Open. If macOS still refuses:
       xattr -dr com.apple.quarantine "/Applications/Evergreen note.app"
2. Apple Silicon Macs only. No account, no login, no network required.
3. All notes stay on this Mac, in {{LIBRARY_DIR}}
   Automatic backups (every 30 min, last 20 kept) go to {{BACKUP_DIR}}
4. Upgrade: drag a newer build over the old one. Your notes live outside the
   app bundle and are untouched.
